# docs/notes

Personal working notes. **Nothing here is about the site** — the site and all
of its documentation live in `portfolio/`.

This directory predates the current site and is kept as a record. It is not
maintained to the same standard as `docs/site/`: entries are written
for one reader, some are stubs, and none of them are a reference anyone else
should rely on.

## What is in here

| Entry | What it is |
| --- | --- |
| `Git Bash Commands.md` | A command cheat-sheet for starting and advancing a repository |
| `installations.md` | Setup notes for a Windows machine |
| `CI-CD Commands.md` | A handful of commonly used pipeline commands |
| `Brainstorm/` | Early design and planning notes, from before the current site |
| `error log/` | Errors hit along the way, kept so the same one is not debugged twice |
| `watchAndLearn/` | Notes taken while following tutorials |
| `youtube_playlist.md` | Links queued for later |
| `Tools.md` | Empty. A placeholder that was never filled |
